# نَسَق كود

واجهة عربية RTL لفحص بنية التطبيقات وأمانها وتبعياتها وقابلية صيانتها

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الحالة الحالية

- صفحة رئيسية متجاوبة
- فحص حقيقي لملفات ZIP داخل متصفح المستخدم دون رفع الكود
- حدود حماية لعدد الملفات والحجم المضغوط والحجم بعد فك الضغط
- كشف أولي للأسرار والملفات الكبيرة والترابط وديون الصيانة ومشكلات التبعيات
- تحليل عميق للتشابك ونقاط الاختناق والاعتمادات الدائرية وتكرار المقاطع
- أولويات تنفيذ تربط كل ملاحظة بدليل وإجراء مقترح وحجم جهد تقريبي
- فحص قواعد Firebase وإعدادات Docker وصلاحيات GitHub Actions وأنماط الحماية الحساسة
- فحص المستودعات العامة على GitHub مباشرة من المتصفح
- GitLab وBitbucket ظاهران كخيارات قادمة ولا يعملان حاليًا
- تقرير تفاعلي بنتائج المشروع والفلاتر وخطة الإصلاح
- حالات التحميل والخطأ والنتائج الفارغة
- دعم التثبيت كتطبيق ويب PWA
- نشر ثابت على Firebase Hosting دون قاعدة بيانات أو حساب مستخدم
- أساسيات SEO وملفات `robots.txt` و`sitemap.xml`

ربط المستودعات الخاصة عبر OAuth غير مفعّل في هذه النسخة لأنه يتطلب بيانات اعتماد خاصة بالمشروع

النتائج مؤشرات ساكنة ومبدئية ولا تشغّل التطبيق ولا تطابق التبعيات مع قاعدة بيانات CVE ولا تثبت خلو المشروع من الثغرات
